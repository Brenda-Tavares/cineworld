概要

CineWorld は公開の映画カタログです。登録は不要で、ログインはなく、ユーザープロファイルも作成しません。

  • 追跡用の Cookie は使用しません。
  • Google Analytics その他の広告・マーケティングサービスは使用しません。
  • 広告は表示せず、Google AdSense も使用しません。
  • 個人データを販売・貸出し、広告目的で第三者と共有することはありません。

取り扱うデータ

お使いのデバイス上：

  • 言語の偏好。選択した言語は、ブラウザの localStorage にキー cineworld_language として保存されます。これはデバイスに書き込まれる唯一のデータです。ユーザー識別情報は含まず、当サイトのブラウザデータを消去すると消えます。

サーバー上：

  • リクエストログ。ホスティング事業者（Vercel）は、IP アドレス、日時、ブラウザ、アクセスされた URL などの技術的なリクエスト情報を記録します。これらのログはセキュリティとサービス運用のためにのみ使用され、ホスティング事業者自身の条項に従って保管されます。
  • 検索語。入力された検索語は、カタログを取得するため TMDB に送信されます。当社が管理するデータベースには保存されません。

氏名、メールアドレス、電話番号、身分証番号、郵便住所、決済情報は収集しません。個人情報を収集するフォームも存在しません。

第三者および移転

サイトの運営には、一部のデータを第三者サービスへ送信する必要があります：

  • TMDB（The Movie Database） — 映画を特定するため検索語を受け取り、カタログデータ、画像、配信事業者の情報を提供します。
  • Google Gemini API — AI 検索を使用されたときのみ、入力されたテキストを受け取ります。その意図を解釈するために使用されます。アクセスキーはサーバーにのみ保持されます。
  • Google Fonts — Inter フォントは Google Fonts から読み込まれます。このリクエストにより、あなたの IP アドレスと参照元ページが Google に伝わります。追跡用 Cookie は含まれません。
  • Google Custom Search API（任意・無効） — コードには補完的なウェブ検索の機能が含まれますが、GOOGLE_SEARCH_API_KEY と GOOGLE_SEARCH_CX が設定された場合のみ有効になります。これらは未設定のため、この連携は無効であり、現時点ではデータを送信しません。
  • Vercel Speed Insights — お使いのブラウザで本ページの読み込み性能（Core Web Vitals：読み込み時間、描画、レイアウトシフト）を計測し、その指標とブラウザの user agent を Vercel に送信します。本サイトで使用しているトラフィック解析ツールはこれのみです。広告用の Cookie は設定しません。
  • Vercel — ホスティングとバックエンドの実行。
  • Font Awesome（cdnjs） — インターフェースアイコン。
  • Wikimedia Commons — フッターに表示される配信サービスのロゴ。

これらの事業者により、ブラジル国外（米国を含む）のサーバーでデータが処理される場合があります。

利用目的

  • 映画カタログと検索結果の表示
  • 各作品の視聴可能なプラットフォームの表示
  • AI 検索の要求に対する解釈
  • 訪問をまたいで選択した言語を保持すること
  • 不正利用や自動化されたアクセスの防止
  • ページの読み込み性能を測定し、体験を改善すること

保持期間

  • 言語の偏好：削除するまでブラウザに保存されます
  • サーバーログ：Vercel の保持ポリシーに従います
  • その他のデータ：リクエストの処理後、当社が保存することはありません

セキュリティ対策

  • HTTPS/TLS による暗号化通信
  • API キーはサーバーの環境変数にのみ保持し、ブラウザには一切公開しません
  • 入力の検証とサニタイズを行い、API データの描画には DOMPurify を使用
  • 厳格な Content Security Policy を設定し、クロスオリジン要求を本番ドメインに限定
  • 悪用とクォータ消費を抑えるため、送信元ごとのリクエスト数を制限

子どものデータ

本サイトは 13 歳未満の子どもを対象としておらず、子どもの個人情報を意図的に収集することはありません。
