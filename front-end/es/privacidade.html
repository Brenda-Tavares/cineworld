Resumen

CineWorld es un catálogo público de películas. No requiere registro, no tiene inicio de sesión y no crea perfiles de usuario.

  • No utilizamos cookies de seguimiento.
  • No utilizamos Google Analytics ni ningún otro servicio de publicidad o marketing.
  • No mostramos publicidad ni utilizamos Google AdSense.
  • No vendemos, alquilamos ni compartimos datos personales con terceros con fines publicitarios.

Datos que Tratamos

En tu dispositivo:

  • Preferencia de idioma. El idioma que eliges se guarda en el localStorage de tu navegador, con la clave cineworld_language. Es el único dato que se guarda en tu dispositivo. No contiene identificador de usuario y desaparece al borrar los datos de navegación del sitio.

En nuestro servidor:

  • Registros de petición. Nuestro proveedor de alojamiento (Vercel) registra datos técnicos de las peticiones, como dirección IP, fecha y hora, navegador y URL visitada. Estos registros se usan solo para la seguridad y la operación del servicio, y se conservan según los términos del propio proveedor.
  • Términos de búsqueda. Los términos que escribes se envían a TMDB para que devuelva el catálogo. No se almacenan en ninguna base de datos nuestra.

No recopilamos nombre, correo electrónico, teléfono, documento, dirección postal ni datos de pago. No existe ningún formulario que recopie datos personales.

Terceros y Transferencias

Para operar el sitio, algunos datos se envían a servicios de terceros:

  • TMDB (The Movie Database) — recibe tus términos de búsqueda para localizar películas y aporta datos de catálogo, imágenes y proveedores de streaming.
  • Google Gemini API — recibe el texto que escribes solo cuando usas la búsqueda por IA. Ese texto se usa para interpretar tu intención de búsqueda. Las claves de acceso permanecen en el servidor.
  • Google Fonts — la tipografía Inter se carga desde Google Fonts. Esa petición expone tu dirección IP y la página de origen a Google. No interviene ninguna cookie de seguimiento.
  • Google Custom Search API (opcional, desactivada) — el código contempla una búsqueda web complementaria que solo se activaría si se configuraran GOOGLE_SEARCH_API_KEY y GOOGLE_SEARCH_CX. No están configuradas, por lo que esa integración está inactiva y hoy no se envía ningún dato a ella.
  • Vercel Speed Insights — mide el rendimiento de esta página en tu navegador (Core Web Vitals: tiempo de carga, renderizado y desplazamiento del diseño) y envía esas métricas y el user agent del navegador a Vercel. Es la única herramienta de análisis de tráfico usada en el sitio. No establece cookies publicitarias.
  • Vercel — alojamiento y ejecución del backend.
  • Font Awesome (cdnjs) — iconos de la interfaz.
  • Wikimedia Commons — logotipos de las plataformas de streaming del pie de página.

Los datos pueden procesarse en servidores fuera de Brasil, incluidos en Estados Unidos, por esos proveedores.

Finalidades

  • Mostrar el catálogo de películas y los resultados de búsqueda
  • Informar dónde está disponible cada título
  • Interpretar la búsqueda por IA cuando se solicite
  • Recordar el idioma elegido entre visitas
  • Proteger el servicio contra el abuso y los accesos automatizados
  • Medir el rendimiento de la página para mejorar la experiencia de carga

Retención

  • Preferencia de idioma: se conserva en tu navegador hasta que la elimines
  • Registros del servidor: según la política de retención de Vercel
  • Resto de datos: no los almacenamos una vez procesada la petición

Medidas de Seguridad

  • Conexión cifrada mediante HTTPS/TLS
  • Claves de API solo en variables de entorno del servidor, nunca expuestas al navegador
  • Validación y saneamiento de las entradas, con DOMPurify al renderizar datos de la API
  • Content Security Policy restrictiva, con las peticiones entre orígenes limitadas al dominio de producción
  • Límite de peticiones por origen para reducir el abuso y el consumo de cuota

Datos de Menores

El sitio no está dirigido a menores de 13 años ni recopila conscientemente datos personales de niños.

Tus Derechos (LGPD/GDPR)

Como no tenemos cuentas, el único dato asociado a ti es la preferencia de idioma en tu propio navegador. Puedes borrarla cuando quieras limpiando los datos del sitio en el navegador. Si tienes dudas sobre los registros de petición o quieres ejercer cualquier derecho previsto en la LGPD o el GDPR, escribe a tavaresbrenda@proton.me.
