概要

CineWorld 是一个公开的电影目录，无需注册，没有登录功能，也不会创建用户资料。

  • 我们不使用追踪 cookie。
  • 我们不使用 Google Analytics，也不使用任何其他广告或营销服务。
  • 我们不展示广告，也不使用 Google AdSense。
  • 我们不出售、出租或出于广告目的与第三方共享个人数据。

我们处理的数据

在你的设备上：

  • 语言偏好。你选择的语言会保存在浏览器的 localStorage 中，键名为 cineworld_language。这是唯一写入你设备的数据。它不包含用户标识符，清理本站的浏览数据后即消失。

在我们的服务器上：

  • 请求日志。我们的托管服务商（Vercel）会记录请求的技术数据，例如 IP 地址、日期时间、浏览器和访问的网址。这些日志仅用于安全和运营，并按托管服务商自身的条款保留。
  • 搜索词。你输入的搜索词会发送给 TMDB 以返回目录内容。搜索词不会存储在我们自己的数据库中。

我们不收集姓名、电子邮箱、电话号码、证件、邮政地址或付款信息。站点中没有任何收集个人数据的表单。

第三方与跨境传输

运行本站需要向第三方服务发送部分数据：

  • TMDB（The Movie Database） — 接收你的搜索词以定位电影，并提供目录数据、图片和流媒体供应商信息。
  • Google Gemini API — 仅在你使用 AI 搜索时接收你输入的文本，用于理解你的搜索意图。访问密钥仅保存在服务器上。
  • Google Fonts — Inter 字体从 Google Fonts 加载。该请求会向 Google 暴露你的 IP 地址和来源页面。此过程不涉及追踪 cookie。
  • Google Custom Search API（可选，已停用） — 代码中包含一项可选的补充网络搜索，只有在配置了 GOOGLE_SEARCH_API_KEY 和 GOOGLE_SEARCH_CX 时才会启用。这两个变量并未配置，因此该集成处于停用状态，目前不会向其发送任何数据。
  • Vercel Speed Insights — 测量本页在你的浏览器中的性能（Core Web Vitals：加载时间、渲染和布局偏移），并将这些指标和浏览器的 user agent 发送给 Vercel。这是本站唯一使用的流量分析工具。它不设置广告 cookie。
  • Vercel — 托管与后端运行。
  • Font Awesome（cdnjs） — 界面图标。
  • Wikimedia Commons — 页脚显示的流媒体平台标志。

上述供应商可能在巴西以外的服务器（包括美国）处理数据。

使用目的

  • 展示电影目录和搜索结果
  • 显示每部影片可在何处观看
  • 在你要求时解读 AI 搜索
  • 在多次访问之间记住你选择的语言
  • 保护服务免受滥用和自动化访问
  • 测量页面性能以改善加载体验

保留期限

  • 语言偏好：保存在你的浏览器中，直至你将其删除
  • 服务器日志：依 Vercel 的保留政策
  • 其他数据：请求处理完毕后我们不予存储

安全措施

  • 通过 HTTPS/TLS 加密传输
  • API 密钥仅存于服务器环境变量，绝不暴露给浏览器
  • 对输入进行校验与清理，渲染 API 数据时使用 DOMPurify
  • 严格的 Content Security Policy，跨源请求仅限于生产域名
  • 按来源限制请求频率，以减少滥用和配额消耗

未成年人数据

本站不面向 13 岁以下儿童，也不会有意收集儿童的个人数据。

您的权利（LGPD/GDPR）

由于我们不设账户，与您关联的唯一数据是您浏览器中的语言偏好。您可以随时通过清理本站的浏览数据将其删除。如对请求日志有疑问，或希望行使 LGPD 或 GDPR 规定的任何权利，请写信至 tavaresbrenda@proton.me。
