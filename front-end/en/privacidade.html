Summary

CineWorld is a public movie catalogue. It requires no sign-up, has no login and creates no user profiles.

  • We do not use tracking cookies.
  • We do not use Google Analytics or any other advertising or marketing service.
  • We do not display advertising and do not use Google AdSense.
  • We do not sell, rent or share personal data with third parties for advertising purposes.

Data We Process

On your device:

  • Language preference. The language you pick is saved in your browser's localStorage, under the key cineworld_language. It is the only data written to your device. It contains no user identifier and disappears when you clear the site's browser data.

On our server:

  • Request logs. Our hosting provider (Vercel) records technical request data such as IP address, date and time, browser and the URL accessed. These logs are used only for security and service operation, and are retained under the hosting provider's own terms.
  • Search terms. The terms you type are sent to TMDB so it can return the catalogue. Terms are not stored in any database we control.

We do not collect name, email, phone number, ID, postal address or payment details. There is no form that collects personal data.

Third Parties and Transfers

Operating the site requires sending some data to third-party services:

  • TMDB (The Movie Database) — receives your search terms to locate films, and provides catalogue data, images and streaming providers.
  • Google Gemini API — receives the text you type only when you use AI search. That text is used to interpret your search intent. Access keys stay on the server.
  • Google Fonts — the Inter typeface is loaded from Google Fonts. That request exposes your IP address and the referring page to Google. No tracking cookie is involved.
  • Google Custom Search API (optional, disabled) — the codebase includes an optional supplementary web search that would only activate if GOOGLE_SEARCH_API_KEY and GOOGLE_SEARCH_CX were configured. They are not configured, so this integration is inactive and no data is sent to it today.
  • Vercel Speed Insights — measures this page's performance in your browser (Core Web Vitals: load time, rendering and layout shift) and sends those metrics and the browser user agent to Vercel. It is the only traffic analysis tool used on the site. It sets no advertising cookie.
  • Vercel — hosting and backend execution.
  • Font Awesome (cdnjs) — interface icons.
  • Wikimedia Commons — streaming platform logos shown in the footer.

Data may be processed on servers outside Brazil, including in the United States, by those suppliers.

Purposes

  • Display the movie catalogue and search results
  • Show where each title is available to watch
  • Interpret AI search when you ask for it
  • Remember your chosen language between visits
  • Protect the service against abuse and automated access
  • Measure page performance to improve load-time experience

Retention

  • Language preference: kept in your browser until you delete it
  • Server logs: according to Vercel's retention policy
  • Everything else: not stored by us once the request has been processed

Security Measures

  • Encrypted connection over HTTPS/TLS
  • API keys held only in server environment variables, never exposed to the browser
  • Input validation and sanitisation, with DOMPurify used when rendering API data
  • Restrictive Content Security Policy, with cross-origin requests limited to the production domain
  • Per-origin request limits to reduce abuse and quota consumption

Children's Data

The site is not directed at children under 13 and does not knowingly collect personal data from children.

Your Rights (LGPD/GDPR)

Because we keep no accounts, the only data associated with you is the language preference in your own browser. You can delete it at any time by clearing this site's browser data. If you have questions about request logs, or wish to exercise any right under the LGPD or the GDPR, write to tavaresbrenda@proton.me.
