第三方同埋跨境傳輸

要運行呢個網站，需要將部分資料傳送俾第三方服務：

  • TMDB（The Movie Database） — 接收你嘅搜尋字詞去搵電影，並提供目錄資料、圖片同串流平台資料。
  • Google Gemini API — 只有喺你用 AI 搜尋嘅時候先會收到你輸入嘅文字，用嚟理解你嘅搜尋意圖。存取金鑰只會留喺伺服器上面。

  • Google Custom Search API（選用，已停用） — 程式碼入面有一項選用嘅補充網上搜尋，只有設定咗 GOOGLE_SEARCH_API_KEY 同 GOOGLE_SEARCH_CX 先會啟動。而家呢兩個變數未設定，所以呢個整合係停用狀態，亦唔會傳送任何資料畀佢。
  • Vercel Speed Insights — 量度呢一頁喺你瀏覽器入面嘅效能（Core Web Vitals：載入時間、渲染同版面位移），並且會將呢啲指標同埋瀏覽器嘅 user agent 傳送俾 Vercel。呢個係本網站唯一使用嘅流量分析工具，佢唔會設定廣告 cookie。
  • Vercel — 託管同後端運行。
  • Font Awesome（cdnjs） — 介面圖示。
  • Wikimedia Commons — 頁尾顯示嘅串流平台標誌。

上述供應商可能會喺巴西以外嘅伺服器（包括美國）處理資料。
