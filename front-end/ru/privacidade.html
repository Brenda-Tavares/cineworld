Кратко

CineWorld — это открытый каталог фильмов. Регистрация не требуется, входа в аккаунт нет, профили пользователей не создаются.

  • Мы не используем отслеживающие cookie.
  • Мы не используем Google Analytics и любые другие рекламные или маркетинговые сервисы.
  • Мы не показываем рекламу и не используем Google AdSense.
  • Мы не продаём, не сдаём в аренду и не передаём персональные данные третьим лицам в рекламных целях.

Какие данные обрабатываются

На вашем устройстве:

  • Языковые настройки. Выбранный вами язык сохраняется в localStorage браузера под ключом cineworld_language. Это единственные данные, записываемые на ваше устройство. Они не содержат идентификатора пользователя и исчезают при очистке данных сайта в браузере.

На нашем сервере:

  • Журналы запросов. Наш хостинг-провайдер (Vercel) записывает технические данные запросов: IP-адрес, дату и время, браузер и запрошенный URL. Эти журналы используются только для безопасности и работы сервиса и хранятся на условиях самого провайдера.
  • Поисковые запросы. Введённые вами запросы отправляются в TMDB, чтобы получить каталог. Они не сохраняются в базах данных, которыми управляем мы.

Мы не собираем имя, адрес электронной почты, номер телефона, документ, почтовый адрес или платёжные данные. На сайте нет ни одной формы, собирающей персональные данные.

Третьи стороны и передача данных

Для работы сайта часть данных передаётся сторонним сервисам:

  • TMDB (The Movie Database) — получает ваши поисковые запросы для поиска фильмов и предоставляет данные каталога, изображения и сведения о стриминговых сервисах.
  • Google Gemini API — получает введённый вами текст только когда вы используете ИИ-поиск. Текст используется для понимания намерения запроса. Ключи доступа остаются на сервере.
  • Google Fonts — шрифт Inter загружается с Google Fonts. При этом запрос передаёт Google ваш IP-адрес и страницу-источник. Отслеживающие cookie не используются.
  • Google Custom Search API (необязательно, отключено) — в коде предусмотрен дополнительный веб-поиск, который активируется только при настройке GOOGLE_SEARCH_API_KEY и GOOGLE_SEARCH_CX. Они не настроены, поэтому интеграция неактивна и сегодня ей ничего не передаётся.
  • Vercel Speed Insights — измеряет производительность этой страницы в вашем браузере (Core Web Vitals: время загрузки, отрисовка и сдвиги макета) и отправляет эти метрики и user agent браузера в Vercel. Это единственный инструмент анализа трафика на сайте. Рекламные cookie не устанавливаются.
  • Vercel — хостинг и выполнение бэкенда.
  • Font Awesome (cdnjs) — значки интерфейса.
  • Wikimedia Commons — логотипы стриминговых платформ в подвале.

Эти поставщики могут обрабатывать данные на серверах за пределами Бразилии, включая серверы в США.

Цели обработки

  • Показ каталога фильмов и результатов поиска
  • Отображение информации о том, где доступен каждый фильм
  • Интерпретация ИИ-поиска по вашему запросу
  • Запоминание выбранного языка между посещениями
  • Защита сервиса от злоупотреблений и автоматизированного доступа
  • Измерение производительности страницы для улучшения загрузки

Сроки хранения

  • Языковые настройки: хранятся в вашем браузере до тех пор, пока вы их не удалите
  • Журналы сервера: в соответствии с политикой хранения Vercel
  • Все остальные данные: мы не храним их после обработки запроса

Меры защиты

  • Шифрование соединения по HTTPS/TLS
  • Ключи API хранятся только в переменных окружения сервера и никогда не попадают в браузер
  • Проверка и очистка входных данных, DOMPurify используется при выводе данных API
  • Строгая Content Security Policy, кросс-доменные запросы ограничены продакшн-доменом
  • Ограничение числа запросов по источнику, чтобы снижать злоупотребления и расход квоты

Данные детей

Сайт не предназначен для детей младше 13 лет и сознательно не собирает персональные данные детей.

Ваши права (LGPD/GDPR)

Поскольку у нас нет аккаунтов, единственные данные, связанные с вами, — это языковые настройки в вашем браузере. Вы можете удалить их в любой момент, очистив данные сайта в браузере. Если у вас есть вопросы о журналах запросов или вы хотите реализовать любое право согласно LGPD или GDPR, напишите на tavaresbrenda@proton.me.
