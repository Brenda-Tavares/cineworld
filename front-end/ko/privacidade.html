요약

CineWorld는 공개 영화 카탈로그입니다. 가입이 필요 없고 로그인이 없으며 사용자 프로필을 만들지 않습니다.

  • 추적용 쿠키를 사용하지 않습니다.
  • Google Analytics를 비롯한 광고·마케팅 서비스는 사용하지 않습니다.
  • 광고를 표시하지 않으며 Google AdSense를 사용하지 않습니다.
  • 개인 데이터를 판매·임대하지 않으며 광고 목적으로 제3자에게 제공하지 않습니다.

처리하는 데이터

사용자의 기기상:

  • 언어 설정. 선택한 언어는 브라우저의 localStorage에 cineworld_language 키로 저장됩니다. 기기에 기록되는 유일한 데이터입니다. 사용자 식별자를 포함하지 않으며 사이트 브라우저 데이터를 지우면 사라집니다.

우리의 서버상:

  • 요청 로그. 호스팅 제공자(Vercel)는 IP 주소, 날짜 및 시간, 브라우저, 접근한 URL 등 요청의 기술적 정보를 기록합니다. 이 로그는 보안과 서비스 운영 목적으로만 사용되며 제공자의 자체 약정에 따라 보관됩니다.
  • 검색어. 입력한 검색어는 카탈로그를 반환받기 위해 TMDB로 전송됩니다. 저희가 관리하는 데이터베이스에는 저장되지 않습니다.

이름, 이메일, 전화번호, 식별번호, 주소 또는 결제 정보를 수집하지 않습니다. 개인정보를 수집하는 양식도 없습니다.

제3자 및 국외 이전

사이트 운영을 위해 일부 데이터가 제3자 서비스로 전송됩니다:

  • TMDB(The Movie Database) — 영화를 찾기 위해 검색어를 전달받고 카탈로그 데이터, 이미지, 스트리밍 제공 정보를 제공합니다.
  • Google Gemini API — AI 검색을 사용할 때에만 입력한 텍스트를 전달받아 검색 의도를 파악하는 데 사용합니다. 접근 키는 서버에만 보관됩니다.
  • Google Fonts — Inter 서체는 Google Fonts에서 불러옵니다. 이 요청으로 IP 주소와 참조 페이지가 Google에 전달됩니다. 추적용 쿠키는 사용되지 않습니다.
  • Google Custom Search API(선택, 비활성) — 코드에는 선택형 보완 웹 검색 기능이 있으나 GOOGLE_SEARCH_API_KEY와 GOOGLE_SEARCH_CX가 설정된 경우에만 활성화됩니다. 현재 미설정 상태이므로 해당 기능은 비활성이며 어떠한 데이터도 전송되지 않습니다.
  • Vercel Speed Insights — 사용자의 브라우저에서 이 페이지의 성능(Core Web Vitals: 로딩 시간, 렌더링, 레이아웃 이동)을 측정하고 해당 지표와 브라우저 user agent를 Vercel로 전송합니다. 사이트에서 사용하는 트래픽 분석 도구는 이것 하나뿐이며 광고용 쿠키를 설정하지 않습니다.
  • Vercel — 호스팅 및 백엔드 실행.
  • Font Awesome(cdnjs) — 인터페이스 아이콘.
  • Wikimedia Commons — 푸터에 표시되는 스트리밍 플랫폼 로고.

해당 제공자에 의해 브라질을 포함한 브라질 외의 서버(미국 포함)에서 데이터가 처리될 수 있습니다.

처리 목적

  • 영화 카탈로그와 검색 결과 표시
  • 각 작품의 시청 가능 플랫폼 안내
  • 요청 시 AI 검색 의도 해석
  • 방문 간 선택 언어 유지
  • 악용 및 자동화된 접근으로부터 서비스 보호
  • 페이지 성능을 측정하여 로딩 경험 개선

보유 기간

  • 언어 설정: 직접 삭제할 때까지 브라우저에 보관
  • 서버 로그: Vercel 보관 정책에 따름
  • 그 외 데이터: 요청 처리 후 저장하지 않음

보안 조치

  • HTTPS/TLS를 통한 암호화 통신
  • API 키는 서버 환경 변수에만 보관되며 브라우저에 노출되지 않음
  • 입력값 검증 및 정규화, API 데이터 렌더링 시 DOMPurify 사용
  • 엄격한 Content Security Policy 적용 및 크로스 오리진 요청을 운영 도메인으로 제한
  • 오용과 할당량 소진을 줄이기 위한 출처별 요청 횟수 제한
