Resumo

O CineWorld é um catálogo público de filmes. Não exige cadastro, não possui login e não cria perfis de usuário.

  • Não utilizamos cookies para rastreamento.
  • Não utilizamos Google Analytics nem qualquer outro serviço de publicidade ou marketing.
  • Não exibimos anúncios e não utilizamos Google AdSense.
  • Não vendemos, alugamos nem compartilhamos dados pessoais com terceiros para fins publicitários.

Dados que Tratamos

No seu dispositivo:

  • Preferência de idioma. O idioma escolhido é salvo no localStorage do seu navegador, na chave cineworld_language. É o único dado gravado no seu dispositivo. Não contém identificador de usuário e some ao limpar os dados de navegação do navegador.

No nosso servidor:

  • Logs de requisição. O provedor de hospedagem (Vercel) registra dados técnicos das requisições, como endereço IP, data e hora, navegador e URL acessada. Esses logs são usados apenas para segurança e operação do serviço, e ficam sob os termos de retenção do próprio provedor.
  • Termos de busca. Os termos que você digita são enviados ao TMDB para que ele retorne o catálogo. Os termos não são armazenados em um banco de dados nosso.

Não coletamos nome, e-mail, telefone, documento, endereço postal nem dados de pagamento. Não existe formulário que colete dados pessoais.

Terceiros e Transferências

Para operar o site, alguns dados são enviados a serviços de terceiros:

  • TMDB (The Movie Database) — recebe os termos de busca para localizar filmes, além de fornecer dados de catálogo, imagens e provedores de streaming.
  • Google Gemini API — recebe o texto digitado por você apenas quando você usa a busca por IA. Esse texto é usado para interpretar a sua intenção de busca. As chaves de acesso ficam somente no servidor.
  • Google Fonts — a fonte Inter é carregada do Google Fonts. Essa requisição carrega o seu endereço IP e a página de origem para o Google. Não há cookie de rastreamento envolvido.
  • Google Custom Search API (opcional, desativado) — o código prevê uma busca online complementar, que só seria ativada se as variáveis GOOGLE_SEARCH_API_KEY e GOOGLE_SEARCH_CX fossem configuradas. Elas não estão configuradas, portanto essa integração está inativa e nenhum dado é enviado a ela hoje.
  • Vercel Speed Insights — mede o desempenho desta página no seu navegador (Core Web Vitals: tempo de carregamento, renderização e deslocamento de layout) e envia essas métricas e o user agent do navegador à Vercel. É a única ferramenta de análise de tráfego usada no site. Não grava cookie de publicidade.
  • Vercel — hospedagem e execução do backend.
  • Font Awesome (cdnjs) — ícones da interface.
  • Wikimedia Commons — logotipos das plataformas de streaming exibidas no rodapé.

Os dados podem ser processados em servidores fora do Brasil, incluindo nos Estados Unidos, por esses fornecedores.

Finalidades

  • Exibir o catálogo de filmes e os resultados de busca
  • Informar onde cada título está disponível para assistir
  • Interpretar a busca por IA quando solicitada
  • Manter o idioma escolhido entre visitas
  • Proteger o serviço contra abuso e acessos automatizados
  • Medir o desempenho da página para melhorar a experiência de carregamento

Retenção

  • Preferência de idioma: mantida no seu navegador até você apagá-la
  • Logs de servidor: conforme a política de retenção da Vercel
  • Demais dados: não são armazenados por nós após o processamento da requisição

Medidas de Segurança

  • Conexão criptografada por HTTPS/TLS
  • Chaves de API mantidas apenas em variáveis de ambiente do servidor, nunca expostas ao navegador
  • Validação e sanitização das entradas, com DOMPurify na renderização de dados da API
  • Content Security Policy restritiva e requisições cross-origin limitadas ao domínio de produção
  • Limite de requisições por origem para reduzir abuso e consumo de cota

Dados de Menores

O site não é direcionado a menores de 13 anos e não coleta intencionalmente dados pessoais de crianças.

Seus Direitos (LGPD/GDPR)

Como não mantemos cadastro, o único dado asociado a você é a preferência de idioma no seu próprio navegador. Você pode apagá-la a qualquer momento limpando os dados do site. Se tiver dúvidas sobre os logs de requisição, ou precisar exercer qualquer direito previsto na LGPD ou no GDPR, escreva para tavaresbrenda@proton.me.
